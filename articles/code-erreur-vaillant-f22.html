Code erreur Vaillant F.22 : manque d’eau ou de pression

Le code F.22 indique généralement un manque d’eau ou une pression insuffisante.

Le code F.22 indique généralement un manque d’eau ou une pression insuffisante.

Identifier le problème

Sur les modèles concernés, le système protège la chaudière lorsque les conditions hydrauliques ne sont pas satisfaisantes. La pression affichée est une première information utile.

Le code peut aussi être lié à la mesure de pression et pas uniquement à une perte d’eau réelle.

Ce que l’on peut constater

Observez si la pression baisse régulièrement, si un radiateur fuit ou si une soupape évacue de l’eau. La procédure de remplissage, lorsqu’elle est autorisée, doit suivre la notice exacte.

Il ne faut jamais remplir à répétition sans rechercher l’origine de la perte de pression.

Faire réparer

Un professionnel vérifie l’étanchéité, le vase d’expansion, la soupape et le capteur de pression si nécessaire.

Signalez le modèle précis et la valeur du manomètre lors de votre appel.

Conseil de sécurité : si vous sentez le gaz, n’actionnez aucun appareil électrique, éloignez-vous et contactez le service d’urgence gaz compétent. Les interventions internes sur une chaudière doivent être réservées à un professionnel qualifié.
